# NUIGURUMI モニター（Processing 4）

Arduinoの2センサーの値を受け取り、グラフ・状態表示・校正・保存を操作する画面です。ハードウェアの配線と初回セットアップは[ルートのREADME](../../README.md)を参照してください。

## 実行する

1. Processing 4のJavaモードで、このフォルダーの `nuigurumi_monitor.pde` を開く。隣の `MonitorProtocol.java` は同じフォルダーに置いたままにする。
2. 実行（▶）を押す。標準のSerialライブラリを使い、追加ライブラリは不要。
3. 実機なしで確認する場合は「デモで試す」。右のバーを動かすと反応が変わる。デモ中は実機への送信をしない。
4. 実機ではデモを終了し、Arduino IDEのシリアルモニター／プロッターを閉じる。
5. 接続先を選んで「接続する」。センサーから手を離して約4秒待つ。
6. ①無負荷 → ②A0基準 → ③A1基準 → 手を離す → ④保存。②③は先に押して安定させ、ボタンを押して約1秒保つ。

書き込み前には「切断する」を押してください。接続中・校正中・受信停止中は、状態に応じて操作が無効になります。「音を戻す」はArduinoの消音解除で、音源を追加する操作ではありません。

## 表示

- A0は緑、A1は紫。最新300サンプル（標準設定で約60秒）の履歴を表示。履歴は保存せず、再接続で消える。
- 校正前・採取中・手を離す待ちでは生のADC値を表示。通常の判定中はArduinoの相対値0〜1000を0〜100%で表示。
- 力や距離の測定値ではない。状態表示はArduinoの判定を使う。
- デモとグラフの色帯は標準の15%・65%・85%を使う。Arduinoのしきい値を変えた場合は、こちらの表示も合わせて調整する。
- 1.8秒以上データが来ない時は現在値を空欄にし、グラフにも切れ目を入れる。「状態通知」で通常ログを要求できる。
- 「校正できませんでした」は複数の失敗原因に共通の表示。無負荷なら手を離して固定を確認し、押し基準なら先に押して保持する。

## 通信

9600 baud、改行区切り。Arduinoからの標準ログ間隔は200msです。

```text
raw0:32 raw1:34 level0:0 level1:0 state:0 ready:1 cal:1 capture:-2 audio:0 muted:0
```

実際の区切りはタブです。`raw0/raw1` はADC値、`level0/level1` は補正後の相対値、`state` は0=無負荷・1=緑・2=黄・3=赤、`cal` は両方の校正が有効、`ready` は離す待ちも終わって判定可能、`audio` はDFPlayer初期化済み、`muted` は消音を示します。

`capture` は -2=停止、-1=無負荷採取、0=A0基準、1=A1基準。画面が送る命令は `v`・`b`・`1`・`2`・`s`・`m` のみです。`v` は通常ログを有効にし、何度送っても同じ状態にします。

`MonitorProtocol.java` は行の欠損・重複・範囲外・矛盾した状態を検査し、不正な行を計測に採用しません。[テスト手順](tests/README.md)も参照してください。
